# Codex Rapido 40k

Riferimento rapido **italiano / inglese** per le regole base di *Warhammer 40,000* 11ª edizione: ricerca in entrambe le lingue, sezioni con menu laterale, schede collegate tra loro, calcolatore per ferire, preferiti e glossario.

Funziona anche **offline**: aprila una volta da Safari/Chrome e poi *Condividi → Aggiungi alla schermata Home*.

> Progetto amatoriale non ufficiale, per uso personale. Non affiliato a Games Workshop. Le descrizioni sono riassunti scritti per la consultazione veloce: in caso di dubbio fanno fede le Core Rules ufficiali e l'app Warhammer 40,000. Warhammer 40,000 è un marchio di Games Workshop Ltd.

## Aggiornare le regole
Tutti i contenuti sono nell'array `E` dentro `index.html` (un oggetto per voce: `id`, `sec`, `en`, `it`, testo `b`). `{A13}` dentro un testo crea un collegamento alla voce A13. Dopo una modifica cambia `CACHE` in `sw.js` (es. `v2`) per forzare l'aggiornamento offline.
